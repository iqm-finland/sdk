IQM client
##########

:Release: |release|
:Date: |today|

Client-side library for connecting to an `IQM <https://iqm.tech/>`_ quantum computer.

Includes `Qiskit <https://qiskit.org/>`_, `Cirq <https://quantumai.google/cirq>`_ and `Qrisp <https://www.qrisp.eu/>`_ adapters for
`IQM's <https://iqm.tech>`_ quantum computers. See user guides for :ref:`Qiskit <User guide Qiskit>`,
:ref:`Cirq <User guide Cirq>` and :ref:`Qrisp <User guide Qrisp>` for introductions on how to install and use the adapters.
