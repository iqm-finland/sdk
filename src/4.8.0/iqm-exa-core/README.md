# EXA: Experiment Automation Core Library

A Python-based framework for the control and measurement of superconducting
qubits.
It supports

- low-level interfaces for R&D and customisation, and
- higher-level abstractions to support automated, user-friendly experiments
  in both pre-defined and ad hoc mode.

The framework is packaged as "Lab in a Box" to enable customer R&D using an
IQM on-premises quantum computer.
