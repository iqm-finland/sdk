QPUPlot#

Module: exa.core.plotting.qpu_plot

class QPUPlot(chip_label, qb_colormap=None, tc_colormap=None, cr_colormap=None, observations=None, aux_colormap=None, save_directory=None, resolution=300, figure_format='png', split_dut_field=None, chip_layout=None)#

Bases: object

Help creating a plot for a given QPU that shows observation data.

Initialize QPUPlot.

Parameters:

  • chip_label (str) – The DUT label of the chip, used to find the respective chip design record.

  • qb_colormap (ListedColormap | None) – If provided, color the qubits in the topology plot based on their data value, otherwise qubits are uncolored.

  • tc_colormap (ListedColormap | None) – If provided, color the couplers in the topology plot based on their data value, otherwise couplers are uncolored.

  • cr_colormap (ListedColormap | None) – If provided, color the computational resonators in the topology plot based on their data value, otherwise computational resonators are uncolored.

  • aux_colormap (ListedColormap | None) – Auxiliary colormap that is used by CDF plot.

  • observations (Sequence[ObservationDefinition] | None) – An optional list of observations passed on initialization, to be used in the plot. More observations can be added via add_observations or add_observations_from_database methods.

  • save_directory (Path | None) – Where to save the figure.

  • resolution (int) – If figures are saved, rasterize with the given value in dpi.

  • figure_format (str) – All figures will be saved in this format, for example, png, jpg, pdf, svg.

  • split_dut_field (Callable[[str], tuple[str, str]] | None) – How to extract component and parameter names from the DUT field. Default assumes that {dut_field}=={component_name}.{parameter_name}.

  • chip_layout (ChipLayout | None) – Providing a chip layout is required if the metro data is not available in the chip design record.

add_observations_from_database(*, latest=True, all_tags=True, dut_fields=None, obs_params=None, run_id=None, tags=None, min_date=None, max_date=None)#

Add observations from database, filtering based on the provided criteria.

Parameters:

  • latest (bool) – Add only the latest observation for each DUT field. Otherwise add all observations for the given filters.

  • all_tags (bool) – Add the observations that satisfy all tags. Otherwise add observations that contain at least one tag if specified in tags.

  • dut_fields (list[str] | None) – The IDs of the type of observation in the database, e.g., component_name.parameter_name.

  • obs_params (list[Parameter] | None) – Add the observations with this parameter for each of the components on the chip if they have it.

  • run_id (UUID | None) – Add only the observations from the specified run ID.

  • tags (list[str] | None) – Tags to filter the observations. If this is the only argument, the latest observations for these tags are returned.

  • min_date (date | str | None) – Exclude observations with earlier created_timestamp. If defined as a string, it should be in ISO-8601 date format. Dates are not aware of timezones. Requires max_date to be set.

  • max_date (date | str | None) – Only include observations with earlier created_timestamp. If defined as a string, it should be in ISO-8601 date format. Dates are not aware of timezones. Requires min_date to be set.

Return type:

None

draw_cdf(observation_types=None, save_directory=None, figsize=(6.0, 4.0), **kwargs)#

Draw a cumulative histogram plot for all the observations of the given obs_types.

The observations for each obs_type will be drawn on its own line, but in the same plot with the rest. The obs_types of the same unit will be plotted on the same plot, otherwise they will be drawn on different plots.

Parameters:

  • observation_types (list[str] | set[str] | None) – The types of observations to plot from observations gathered in QPUPlot.

  • save_directory (Path | str | None) – If provided, the resulting plot is saved to that directory.

  • figsize (tuple[float, float]) – Width, height in inches.

  • **kwargs – kwargs for plot multi cdf method.

Returns:

The CDF plot for each unit.

Return type:

dict[str, Figure]
