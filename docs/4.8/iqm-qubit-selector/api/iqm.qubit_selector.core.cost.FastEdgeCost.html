FastEdgeCost#

Module: iqm.qubit_selector.core.cost

class iqm.qubit_selector.core.cost.FastEdgeCost(metrics, readout_mode=ReadoutMode.NONE)#

Bases: CostCalculatorBase[LayoutScore]

Score layouts from QPU metrics alone, without transpiling the circuit.

Layouts from the enumerators put every 2-qubit gate on a coupled pair, so the circuit needs no routing and its gates can be scored as they are. The error budget of a layout is:

total = sum(count * -log(two_qubit_fidelity[edge]))
      + sum(count * -log(single_qubit_fidelity[qubit]))
      + sum(-log(readout_fidelity[qubit]))     # only when readout_mode is not NONE

A missing metric adds infinite error, so a layout on an uncalibrated qubit or pair never wins instead of being scored as perfect. A fidelity outside (0, 1] raises ValueError: it means the calibration data is corrupt, and no ranking based on it can be trusted.

Parameters:

  • metrics (MetricsData) – QPU metrics used for scoring.

  • readout_mode (ReadoutMode) – Which readout metric to include, if any.
