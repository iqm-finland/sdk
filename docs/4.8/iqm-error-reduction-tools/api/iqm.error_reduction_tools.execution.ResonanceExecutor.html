iqm.error_reduction_tools.execution.ResonanceExecutor#

class iqm.error_reduction_tools.execution.ResonanceExecutor(client, compilation_options=None)#

Bases: Executor

Runs circuits on an IQM quantum computer through IQM Resonance or a local IQM server.

Parameters:

  • client (IQMClient) – Client connected to the quantum computer.

  • compilation_options (dict[str, Any] | None) – Extra entries for the compiler context, e.g. a dynamical decoupling strategy.

Attributes

quantum_computer

Return the name of the quantum computer the client is connected to.

supports_twirling

Return False for QPUs with computational resonators, where twirling is not supported.

submit(circuits, shots, *, calibration=False)#

Compile the circuits and submit them as one playlist job.

Parameters:

  • circuits (Sequence[Circuit]) – Circuits in the native gate set.

  • shots (int) – Shots per circuit.

  • calibration (bool) – Whether the job characterizes the readout, so that it is compiled without the compilation options.

Returns:

The submitted job.

Return type:

SubmittedJob

collect(job)#

Wait for a job and return its counts.

A job submitted in another session is restored from its identifier and compiler context.

Parameters:

job (SubmittedJob) – The submitted job.

Returns:

One counts dictionary per circuit, in submission order.

Raises:

  • TypeError – If the identifier does not belong to a playlist job.

  • ValueError – If a restored job carries no compiler context.

Return type:

list[dict[str, int]]
