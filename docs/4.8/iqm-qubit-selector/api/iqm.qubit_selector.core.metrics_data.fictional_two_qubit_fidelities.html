iqm.qubit_selector.core.metrics_data.fictional_two_qubit_fidelities#

iqm.qubit_selector.core.metrics_data.fictional_two_qubit_fidelities(cz_resonator, move, arch)#

Return effective qubit-qubit CZ fidelities for a Star architecture.

A Star QPU has no direct qubit-qubit CZ: CZ(q1, q2) runs as MOVE(q2, r) CZ(q1, r) MOVE(q2, r) through a shared computational resonator r, so its fidelity is taken as cz(q1, r) * move(q2, r) ** 2 ([1]; the same model as IQMTarget._create_fictional_cz_properties). The pairs are those simplify_architecture() creates, so they match the collapsed coupling graph.

When a pair can be routed several ways (either qubit moved, or through several resonators), the best fidelity is kept, since the transpiler is free to pick that route. Pairs missing a metric are left out, so the cost model treats them as uncalibrated rather than perfect.

Parameters:

  • cz_resonator (Mapping[str, float]) – Qubit-resonator CZ fidelities, keyed as in FullMetricsData.cz_resonator.

  • move (Mapping[str, float]) – Single-MOVE fidelities, keyed as in FullMetricsData.move.

  • arch (DynamicQuantumArchitecture) – The raw Star architecture, used for its CZ and MOVE loci.

Returns:

Two-qubit fidelities with both orderings of each pair, for MetricsData.two_qubit.

Return type:

dict[str, float]
