AllToAllEnumerator#

Module: iqm.qubit_selector.core.enumerator

class iqm.qubit_selector.core.enumerator.AllToAllEnumerator(node_labels, max_num_layouts=2000, seed=0)#

Bases: BaseEnumerator

Enumerate layouts on a complete coupling graph.

Every k-subset of the QPU’s qubits is a valid layout here, so VF2 would prune nothing; the subsets are generated directly instead.

Only one assignment of logical to physical qubits is tried per set. Trying all k! would use up the budget on reshuffling a few sets, and on a randomised 20-qubit star the best assignment beat the canonical one by only about 0.02 nats (under 2% relative error). VF2Enumerator makes the same trade-off.

When C(N, k) exceeds max_num_layouts, a seeded uniform sample of the subsets is returned; taking them in label order would never reach the high-numbered qubits.

Parameters:

  • node_labels (list[str]) – Names of the QPU’s qubits.

  • max_num_layouts (int) – Maximum number of layouts to return.

  • seed (int | None) – Seed for the sample; None for a fresh draw on every call.

Return up to max_num_layouts qubit sets of size num_circuit_qubits.

The interaction graph is only validated: on a complete graph any qubit set can host it.

Parameters:

  • interaction_graph (dict[frozenset[str], int]) – 2-qubit interaction graph over logical qubit names.

  • num_circuit_qubits (int) – Number of qubits in the circuit.

Returns:

Layouts in node_labels order.

Raises:

ValueError – If the circuit needs no qubits, more qubits than the QPU has, or fewer qubits than its interaction graph involves.
