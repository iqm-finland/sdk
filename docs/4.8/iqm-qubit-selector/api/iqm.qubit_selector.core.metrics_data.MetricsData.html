MetricsData#

Module: iqm.qubit_selector.core.metrics_data

class iqm.qubit_selector.core.metrics_data.MetricsData(two_qubit=<factory>, single_qubit=<factory>, readout=<factory>)#

Bases: object

QPU metrics the cost model scores layouts with.

Single-qubit metrics are keyed by qubit name (e.g. "QB1"), two-qubit fidelities by two_qubit_key() of an ordered pair. Both orderings of a pair must be present; two_qubit_fidelities() adds them.

Without a server, build it by hand:

metrics = MetricsData(
    two_qubit=two_qubit_fidelities({("QB1", "QB2"): 0.995, ("QB2", "QB3"): 0.990}),
    single_qubit={"QB1": 0.999, "QB2": 0.998, "QB3": 0.997},
    readout={
        ReadoutMode.FIDELITY: {"QB1": 0.98, "QB2": 0.97, "QB3": 0.96},
        ReadoutMode.QNDNESS: {"QB1": 0.95, "QB2": 0.94, "QB3": 0.93},
    },
)

Only the readout entry for the requested ReadoutMode is read, so others may be left out.

Attributes

two_qubit

Two-qubit (CZ) gate fidelities, keyed by two_qubit_key().

single_qubit

Single-qubit gate fidelities, keyed by qubit name.

readout

Readout metrics per qubit, keyed by the ReadoutMode that selects them.
