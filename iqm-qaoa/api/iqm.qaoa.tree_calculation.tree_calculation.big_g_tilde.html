big_g_tilde#

iqm.qaoa.tree_calculation.tree_calculation.big_g_tilde(a_t, beta_t)#

Calculates the function \(\tilde{G}(a_t)\) from equations (A47) and (A48) from [8].

Parameters:

  • a_t (int) – The variable \(a_t\).

  • beta_t (ndarray[tuple[Any, ...], dtype[float64]]) – An array containing the QAOA beta angles from \(\beta_t\) to \(\beta_p\), where \(p\) is the number of QAOA layers.

Returns:

The result of the calculation.

Return type:

complex128
