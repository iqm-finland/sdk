class iqm.error_reduction_tools.zne.zne_technique.ZNE(noise_factors=(1, 3, 5))#

Bases: Technique

Configuration of zero-noise extrapolation: which noise factors are executed.

The noise of the target is amplified by global folding, U -> U (U^dagger U)^s, which gives the odd noise factor 1 + 2s.

Attributes

noise_factors
