iqm.error_reduction_tools.workflow.ErrorReductionWorkflow#

class iqm.error_reduction_tools.workflow.ErrorReductionWorkflow(targets, observables, technique, *, client, compilation_options=None, twirling_configuration=None, rec_configuration=None, shots=None, backend=None)#

Bases: object

Workflow to estimate observables of target circuits with an error reduction technique.

The four stages are separate methods, and each stores its output on the workflow: plan() sets execution_plan, submit() sets submission, collect() sets counts, and estimate() sets result. run() does all four in one call.

submit() and collect() use the quantum computer. plan() and estimate() do not, and can be repeated with other settings.

save() and load() can be used after the collection and before the estimation, respectively, to store and retrieve the workflow state from a file.

Parameters:

  • targets (Sequence[object]) – Circuits whose observables are estimated, transpiled to the native gate set and the physical qubits of the quantum computer: iqm.pulse.Circuit, qiskit or Qrisp circuits, or anything else canonicalize_circuit() accepts. They are converted to iqm.pulse.Circuit.

  • observables (ObservableLike | Sequence[ObservableLike]) – One observable or a sequence of observables, each a sum of I/Z Pauli terms, applied to every target. See build().

  • technique (Technique) – The error reduction technique, e.g. ZNE or CDR.

  • client (IQMClient) – Client connected to the IQM quantum computer the circuits run on.

  • compilation_options (dict[str, Any] | None) – Extra entries for the compiler context, e.g. a dynamical decoupling strategy. The readout calibration job is compiled without them.

  • twirling_configuration (TwirlingConfiguration | None) – Twirling configuration, or None to execute every variant once as it is.

  • rec_configuration (RECConfiguration | Mapping[str, np.ndarray] | None) – Readout error characterization configuration, or None for no readout error mitigation. Readout assignment matrices of an earlier characterization, e.g. the readout_errors of another workflow, are used instead of a new calibration job.

  • shots (int | None) – Total shots of each variant, split over its twirling instances. None uses 20 000. A technique can set its own shots for some variants, which override these with a warning.

  • backend (IQMBackendBase | None) – IQM Qiskit backend the targets were transpiled for, used to name the qubits of qiskit and Qrisp targets. None names qubit i QB{i + 1}.

Raises:

  • TypeError – If a target is of an unsupported type.

  • ValueError – If the reused readout assignment matrices do not cover every measured qubit.

estimate(estimation, *, apply_rem=None, bootstrap_samples=0, bootstrap_seed=0)#

Estimate the observables of every target from the collected counts.

Parameters:

  • estimation (Estimation) – Post-processing settings of the technique, e.g. ZNEEstimation.

  • apply_rem (bool | None) – Whether to mitigate readout errors. None mitigates them when they were characterized.

  • bootstrap_samples (int) – Number of bootstrap samples for the standard deviations, 0 for none. Each sample resamples the counts of every instance and repeats the whole estimation.

  • bootstrap_seed (int | None) – Seed of the resampling.

Returns:

The estimate, also stored as result.

Raises:

  • RuntimeError – If no counts have been collected.

  • ValueError – If the estimation does not match the technique, readout errors are to be mitigated but were not characterized, or bootstrap_samples is 1.

Return type:

EstimationResult

run(estimation, *, apply_rem=None, bootstrap_samples=0, bootstrap_seed=0)#

Run every remaining stage, from planning to estimation, and wait for the quantum computer.

Stages that have already run are not repeated, so a loaded or partly run workflow continues where it stopped. The arguments are checked before anything is submitted.

Parameters:

  • estimation (Estimation) – Post-processing settings of the technique, e.g. ZNEEstimation.

  • apply_rem (bool | None) – Passed to estimate().

  • bootstrap_samples (int) – Passed to estimate().

  • bootstrap_seed (int | None) – Passed to estimate().

Returns:

The estimate, also stored as result.

Raises:

ValueError – If an argument is invalid, see estimate().

Return type:

EstimationResult
