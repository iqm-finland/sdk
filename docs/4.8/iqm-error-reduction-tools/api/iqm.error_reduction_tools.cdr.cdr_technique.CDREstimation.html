iqm.error_reduction_tools.cdr.cdr_technique.CDREstimation#

class iqm.error_reduction_tools.cdr.cdr_technique.CDREstimation(combine='group', min_training_spread=0.05, warn_on_extrapolation=True)#

Bases: Estimation

Regression settings of Clifford data regression. Can be changed after execution.

A line exact = a * measured + b is fitted through the training circuits and evaluated at the measured value of the target.

Attributes

combine

"per_term" fits one line per Pauli term and then combines the terms.

min_training_spread

Warn when the measured training values of a column span less than this, since the slope is then ill-determined.

warn_on_extrapolation

Warn when the measured target value lies outside the range of the measured training values.

combine: Literal['per_term', 'group'] = 'group'#

"per_term" fits one line per Pauli term and then combines the terms. "group" combines the terms into the observables first and fits one line per observable.

min_training_spread: float = 0.05#

Warn when the measured training values of a column span less than this, since the slope is then ill-determined. 0 disables the check.

warn_on_extrapolation: bool = True#

Warn when the measured target value lies outside the range of the measured training values.
