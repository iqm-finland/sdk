Grid2DQPU#

Module: iqm.qaoa.transpiler.quantum_hardware

class iqm.qaoa.transpiler.quantum_hardware.Grid2DQPU(num_rows, num_columns)[source]#

Bases: QPU

Class for 2D rectangular QPU.

Contains variables for number of rows and columns, which determine the hardware graph and layout. Also contains a simple embedded_chain() method to embed a chain in the hardware graph.

Parameters:

  • num_rows (int) – The number of rows in the grid.

  • num_columns (int) – The number of columns in the grid.
